# Plano de implementação — phpList 3.7.0

**Objetivo:** atualizar o núcleo NFS para a distribuição de produção phpList 3.7.0, preservar apenas os hooks comuns necessários e produzir composições locais validadas para Saldo e SegurosMais.

**Limites:** nenhuma ligação ou alteração em servidores/BD de produção; os `config.php` reais e os plugins privados permanecem nos overlays ignorados; SimulaçãoCreditoPessoal não recebe um novo artefacto operacional.

## 1. Linha de base e recuperação

- Confirmar o estado Git e preservar alterações preexistentes.
- Manter a tag `pre-phplist-3.7.0-20260821` no commit anterior à migração.
- Manter o backup externo datado dos ficheiros locais não integrados.
- Validar o arquivo oficial `phplist-3.7.0.tgz` com o manifesto SHA-256 oficial.

## 2. Testes de aceitação antes da integração

- Substituir os pressupostos 3.6.17 nos testes NFS por 3.7.0.
- Exigir `deploy/common/root/lists/` e `deploy/common/VERSION`.
- Validar hooks NFS, ausência de configuração privada no núcleo e isolamento Saldo/SegurosMais.
- Compor cada site num diretório temporário e verificar que o overlay não reintroduz núcleo antigo.
- Fazer os testes falharem contra o estado 3.6.17 antes da implementação.

## 3. Integração do núcleo

- Integrar o código upstream correspondente à versão 3.7.0.
- Resolver os ficheiros comuns que também contêm hooks NFS: `connect.php`, `lib.php`, `pluginlib.php`, `spageedit.php` e `index.php`.
- Comparar o resultado com a distribuição oficial completa.
- Adaptar o gerador para usar diretamente o package de produção 3.7.0, incluindo dependências, UI e plugins oficiais.

## 4. Overlays e compatibilidade

- Inventariar versões e requisitos dos plugins de Saldo e SegurosMais.
- Executar lint dos plugins nas versões PHP compatíveis com phpList 3.7.0.
- Validar as duas variantes de `NFSCustomizationsPlugin` e os respetivos redirects.
- Comparar as opções de configuração 3.6.17/3.7.0 sem revelar valores secretos.
- Retirar do overlay Saldo qualquer cópia antiga do núcleo ou modo de debug que pudesse sobrepor 3.7.0.

## 5. Artefactos e documentação

- Gerar `deploy/common/root/lists/`, `deploy/common/VERSION` e o manifesto SHA-256.
- Produzir a lista exaustiva de elementos obsoletos entre as distribuições.
- Criar `docs/DEPLOY-PHPLIST-3.7.0.md` com upload FTP manual, preservação de dados, upgrade de BD, validação e rollback.
- Atualizar a documentação canónica da estratégia e das customizações.

## 6. Verificação final

- Executar testes estruturais, overlays, checklist NFS, PHP lint e validações de composição.
- Procurar credenciais versionadas e referências operacionais indevidas à 3.6.17.
- Confirmar que Saldo fica tecnicamente preparado, assinalando como bloqueio qualquer requisito de PHP/servidor não verificável localmente.
- Confirmar SegurosMais como composição preparada, sem publicação.
- Registar o trabalho no log transversal sem o incluir no commit deste repositório.
